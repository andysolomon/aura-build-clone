A handful of shortcuts cover most of what you do in the app. On macOS, use `Cmd` wherever you see `Ctrl/Cmd`. On Windows and Linux, use `Ctrl`.

## All shortcuts

| Action | Shortcut | Where |
| --- | --- | --- |
| Send the prompt | `Enter` | Composer |
| Add a new line | `Shift+Enter` | Composer |
| Paste an image as an attachment | `Ctrl/Cmd+V` | Composer |
| Undo a manual edit | `Ctrl/Cmd+Z` | Editor |
| Redo a manual edit | `Ctrl/Cmd+Shift+Z` | Editor |
| Select an element | Click | Design mode |
| Edit text inline | Double-click | Design mode |
| Finish editing text | `Enter` or `Escape` | Design mode, while editing text |
| Clear the selection | `Escape` | Design mode |
| Save code changes | `Ctrl/Cmd+S` | Code view, after pressing **Edit** |

## Composer

`Enter` sends right away, so use `Shift+Enter` when you want to write a longer prompt over several lines, like a list of sections.

```
Landing page for Tally, a habit tracker for remote teams.
Sections: hero, logo strip, 3 features, pricing, FAQ, footer.
Tone: calm and confident.
```

Besides pasting, you can drag and drop images onto the composer, or use the paperclip button. Up to 4 images per prompt.

## Editor

Undo and Redo apply to **manual edits**: changes you make in Design mode, like inline text edits, class changes, or moving and deleting elements. The same actions are available as buttons in the top bar.

AI changes are saved as versions instead. To go back past a prompt, press **Restore** on an earlier version card in the chat.

## Design mode

- Click to select. Use **select parent** in the Inspector to widen the selection to the containing element.
- Double-click text to edit it in place. `Enter` or `Escape` finishes.
- `Escape` with nothing being edited clears the selection.

> Tip: For a quick copy pass, stay in Design mode and work down the page: double-click, type, `Enter`, repeat. It's the fastest way to replace placeholder copy.

## Code view

The Code view is read-only until you press **Edit**. Then it works as a text editor. Press `Ctrl/Cmd+S` or the **Save** button to apply your changes to the page.
