Events

Webhooks

Parcelwise sends an event to your endpoint whenever a shipment changes state, so you never have to poll for tracking updates.

POST /v2/webhook_endpoints

{

  "url": "https://acme.dev/hooks/parcels",

  "events": ["shipment.delivered", "label.purchased"]

}

Event delivery

Respond with any 2xx status within 10 seconds to acknowledge an event. Unacknowledged events are retried automatically, and every attempt is listed in your dashboard.
